Authentication
- Login screen at /login with email and password fields
- Passwords are stored as bcrypt hashes in the users table
- Use express-session for session management
- All views require authentication — redirect to /login if no active session
- POST /auth/login validates credentials with bcrypt and redirects to /orders on success
- GET /auth/logout destroys the session and redirects to /login

---

Views:

1. Orders (/orders)
- Table listing all orders: date, negocio, status, total, actions
- Filter by status (pendiente, confirmado, cancelado) and date range
- Click into order detail: shows all fields, renders the items JSONB as a readable line-item list
- Can edit status and total
- Can cancel an order (sets status to cancelado)

2. Clients (/clients)
- Table listing all clients: codigo_cliente, negocio, activo
- Click into client detail which shows:
  - Editable fields: negocio, sucursal, razon_social, rut, direccion_facturacion, direccion_entrega, horario_entrega, activo
  - Products section: table with product name, costo (from products table), precio_cliente (from client_products), and % sobre venta calculated as precio_cliente / costo shown as a ratio (e.g. 1.47x). Allow inline editing of precio_cliente. Allow adding products from the catalog via a searchable dropdown.
  - Phones section: list of phones from client_phones with their label. Allow adding new phones and deactivating existing ones.

3. Products (/products)
- Table listing all products: codigo_prod, nombre, costo, activo
- Inline or modal edit for nombre, costo, descripcion, unidad, activo
- Button to add a new product
- Search/filter by name
